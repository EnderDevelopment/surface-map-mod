# Surface Map Mod

Full-screen surface-only world map for Minecraft 1.26.2

## Features

- Full-screen surface-only world map
- Waypoint system for marking important locations

## Requirements

- Minecraft 1.26.2
- Fabric Loader 0.16.0 or later
- Fabric API

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/surface-map-mod/releases).
2. Place the downloaded JAR file in your `mods` folder.
3. Launch Minecraft with Fabric.

## Usage

- Press the `M` key to open the full-screen surface-only world map.
- Use the waypoint system to mark important locations.

## Configuration

The mod does not have a configuration file. All settings are hardcoded.
